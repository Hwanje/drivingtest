# 운전면허 장내기능시험 연습 프로그램

대한민국 자동차운전면허 **장내기능시험(기능시험)** 을 브라우저에서 연습할 수 있는 시뮬레이터입니다.
실제 시험 순서 — 안전벨트 · 시동 → **운전장치 조작 평가** → 출발 → 직각주차 → 신호교차로 →
경사로 → 가속구간 → 돌발상황 → 철길건널목 → 종료 — 를 그대로 따라가며,
100점에서 시작해 감점되고 **80점 이상이면 합격**입니다.

가장 큰 특징은 **조작이 필요한 순간마다 화면 구석 박스에 그 기능을 실제로 수행하는
자동차 부품이 3D로 나타난다**는 점입니다. 시험관이 "좌측 방향지시등을 켜십시오"라고 하면
스티어링 컬럼과 방향지시등 레버가 나타나 레버가 실제로 아래로 내려가는 모습을 보여 주고,
"와이퍼를 작동시키십시오"라고 하면 와이퍼 레버가 단수별로 내려가는 모습을 보여 줍니다.

라이브러리 의존성이 전혀 없습니다. 3D 렌더러부터 물리 · 채점 엔진 · 효과음까지 모두 직접 구현했습니다.

---

## 실행 방법

ES 모듈을 쓰기 때문에 `file://` 로 직접 열면 동작하지 않습니다. 정적 서버로 띄워 주세요.

```bash
# 저장소 폴더에서
python3 -m http.server 8000
# 또는
npx serve .
```

브라우저에서 <http://localhost:8000> 을 엽니다.
최신 Chrome · Edge · Firefox · Safari 에서 동작하며, 별도의 설치나 빌드 과정이 없습니다.

## 조작

| 키 | 기능 | 키 | 기능 |
|---|---|---|---|
| `↑` / `W` | 가속 페달 | `↓` / `S` | 브레이크 |
| `←` `→` / `A` `D` | 조향 | `1` `2` `3` `4` | P · R · N · D 변속 |
| `Enter` | 시동 / 시동 끄기 | `Space` | 주차 브레이크 |
| `B` | 안전벨트 | `Q` / `E` | 좌 / 우 방향지시등 |
| `Z` | 와이퍼 (OFF→INT→LO→HI) | `X` | 전조등 (OFF→미등→전조등) |
| `H` | 비상점멸등 | `C` | 시점 전환 (운전석 / 후방 / 부감) |
| `Tab` | 3D 부품 직접 넘겨 보기 | `Esc` | 부품 자동 표시로 복귀 |
| `P` | 일시정지 | `R` | 처음부터 다시 |

화면 오른쪽 패널의 버튼으로도 모두 조작할 수 있습니다.
`☔ 빗방울` 을 켜면 앞유리에 물방울이 맺히고, 와이퍼를 작동시키면 실제로 닦여 나갑니다.

## 3D 부품 뷰어

구석 박스에 나타나는 부품은 10가지입니다. 시험관 지시, 감점 경고, 직접 조작 중
가장 우선순위가 높은 것이 자동으로 표시되고, `Tab` 으로 직접 넘겨 볼 수도 있습니다.

| 부품 | 표현 |
|---|---|
| 방향지시등 레버 | 스티어링 컬럼 좌측 레버가 좌회전 시 내려가고 우회전 시 올라감 |
| 와이퍼 레버 | 우측 레버가 단수(OFF·INT·LO·HI)만큼 내려가고 INT 에서는 조절 링이 회전 |
| 전조등 스위치 | 좌측 레버 끝 다이얼이 OFF → 미등 → 전조등으로 회전 |
| 비상점멸등 스위치 | 센터페시아 버튼이 눌리고 빨간 삼각형이 점멸 |
| 변속 레버 | 게이트를 따라 P · R · N · D 로 이동, 현재 단 점등 |
| 주차 브레이크 | 레버가 라쳇을 따라 올라가고 내려감 |
| 안전벨트 | 벨트가 B필러에서 버클까지 대각선으로 이동 |
| 엔진 시동 버튼 | 버튼이 눌리고 표시등이 대기(점멸) → 시동(녹색)으로 변화 |
| 스티어링 휠 | 조향각의 약 8배로 회전, 각도 표시 |
| 가속 · 제동 페달 | 밟는 정도에 따라 각각 기울어짐 |

## 채점 기준

100점에서 시작해 감점하고 **80점 이상이면 합격**입니다.

| 항목 | 감점 | 항목 | 감점 |
|---|---|---|---|
| 방향지시등 미작동 | 5 | 지시속도 위반(과속) | 10 |

| 급조작 · 급출발 | 7 | 경사로 30초 내 출발 실패 | 10 |
| 주차 브레이크 미해제 출발 | 10 | 돌발상황 조치 미흡 | 10 |
| 직각주차 미완료 · 시간 초과 | 10 | 철길건널목 일시정지 위반 | 10 |
| 종료 조작 미이행 | 10 | | |

### 실격 사유

- 검지선 접촉 · 코스 이탈
- 안전벨트를 착용하지 않고 주행
- 신호 위반(적색신호에 정지선 통과)
- 경사로에서 1m 이상 후방 밀림
- 출발 지시 후 30초 이내 미출발
- 시험시간(10분) 초과
- 최종 점수 80점 미만

> 실제 시험의 규정과 채점 기준은 도로교통공단 공식 안내를 따릅니다.
> 이 프로그램은 공개된 기준을 바탕으로 재구성한 **연습용**이며, 세부 배점과
> 코스 치수는 실제 시험장과 다를 수 있습니다.

## 코스

주행로 폭은 4m이고, 축에 정렬된 사각형들의 합집합으로 코스를 정의한 뒤 그 경계를 그대로
**검지선**으로 씁니다. 덕분에 네 바퀴의 접지점 판정이 정확하고, 노면 폴리곤도 같은 정의에서
자동 생성됩니다. 검지선에 0.3m 이내로 접근하면 먼저 경고하고, 실제로 넘어가면 실격입니다.

```
      ┌──────── 직각주차 ────────┐
      │        ┌──┐              │
 출발 ●━━━━━━━━┷━━┷━━━━━━━━━━━━━━╋━ 신호교차로
                                 ┃
                            경사로┃ (오르막 → 정지구간 → 내리막)
                                 ┃
 종료 ●━━━━━┓              ┏━━━━━┛
            ┃              ┃
   철길건널목┃              ┃
            ┗━━━━━━━━━━━━━━┛
              가속구간 · 돌발상황
```

- **직각주차** : 폭 2.6m · 깊이 5m 구획에 후진으로 진입, 네 바퀴가 모두 들어간 채 정지 (2분 제한)
- **신호교차로** : 12초 녹색 / 3초 황색 / 11초 적색 주기, 정지선 준수
- **경사로** : 오르막 10m · 최고 0.9m(구배 약 9%), 노란 표지 기둥 사이 정지구간에
  앞바퀴를 세우고 30초 내 출발. 브레이크를 놓으면 실제로 뒤로 밀린다
- **가속구간** : 20m 구간을 20km/h 이상으로 통과
- **돌발상황** : 표지판 점등 후 2초 이내 정지 + 비상점멸등
- **철길건널목** : 정지선 앞 일시정지

## 구조

```
index.html            화면 구성
styles.css            스타일
src/
  main.js             진입점 · 게임 루프 · 카메라 · 이벤트 배선
  gfx/
    math.js           벡터 · 4x4 행렬 · 각도 유틸
    mesh.js           폴리곤 메시, 장면 그래프 노드, 도형 빌더
    renderer.js       소프트웨어 3D 렌더러 (근평면 클리핑 → 투영 → 깊이 정렬 → 채우기)
  sim/
    course.js         코스 형상 · 노면 표시 · 구조물 · 경사로 높이 함수
    vehicle.js        차량 거동(자전거 기구학 + 종방향 동역학)
    carmodel.js       차량 외장 3D 모델 + 운전석 실내(1인칭용)
    exam.js           시험 진행 상태기계 · 감점 · 실격 판정
  parts/
    carparts.js       조작 부품 10종의 3D 모델과 애니메이션
    viewer.js         구석 부품 박스(우선순위 큐 · 카메라 연출)
  ui/
    input.js          키보드 · 화면 버튼 입력
    audio.js          Web Audio 합성 효과음 + 시험관 음성 안내(TTS)
    hud.js            계기판 · 미니맵 · 와이퍼/빗방울 효과
```

### 렌더러

`src/gfx/renderer.js` 는 캔버스 2D 위에서 도는 소프트웨어 폴리곤 렌더러입니다.

1. 장면 그래프를 순회하며 각 면의 정점을 뷰 공간으로 변환
2. 근평면(`z <= -near`)에 대해 Sutherland–Hodgman 클리핑
3. 뉴웰 법선으로 평면 음영 계산 (모든 면은 양면으로 그리고 법선을 카메라 쪽으로 뒤집음)
4. 원근 투영 후 거리 기반 안개 적용
5. **레이어 우선, 그다음 먼 것부터** 정렬하여 채우기

레이어는 겹쳐 있는 평평한 노면(바닥 0 → 검지선 1 → 아스팔트 2 → 노면표시 3)에만 쓰고,
입체물은 모두 레이어 4로 두어 깊이 순서대로 그려집니다.

### 차량 거동

자전거 기구학(`θ' = v/L · tan δ`)에 종방향 동역학을 얹었습니다.
크리프 주행, 경사로에서의 후방 밀림, 속도에 따른 조향 응답 변화, 셀프 얼라이닝,
정지 마찰(브레이크가 중력 성분을 이기면 완전히 정지)을 모두 반영해
0~40km/h 구간에서 실제 자동변속기 차량의 느낌에 가깝게 맞췄습니다.

## 알려진 제약

- **자동변속기 차량(2종 보통 오토) 기준**입니다. 수동변속기의 클러치 조작과
  "엔진 시동 꺼짐" 감점은 구현하지 않았습니다.
- 시험관 음성 안내는 브라우저의 `speechSynthesis` 를 사용하므로,
  한국어 음성이 설치되지 않은 환경에서는 자막만 표시됩니다.
- 코스 치수는 실제 시험장과 동일하지 않습니다. 회전부는 키보드 조작을 고려해
  실제보다 조금 넉넉하게 잡았습니다.
