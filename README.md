# 운전면허 장내기능시험 연습 프로그램 — 제1종 보통 (자동변속기)

대한민국 자동차운전면허 **제1종 보통면허 장내기능시험**을 브라우저에서 연습할 수 있는
시뮬레이터입니다. 시험 차량은 실제와 같은 **1톤 화물차(자동변속기)** 이고, 코스 치수는
도로교통법 시행규칙 별표 23의 제1종 보통면허 기준을 따랐습니다.

실제 시험 순서 — 안전벨트 · 시동 → **운전장치 조작 평가** → 출발 → 직각주차 → 신호교차로 →
경사로 → 가속구간 → 돌발상황 → 철길건널목 → 종료 — 를 그대로 따라가며,
100점에서 시작해 감점되고 **80점 이상이면 합격**입니다.

가장 큰 특징은 **조작이 필요한 순간마다 화면 구석 박스에 그 기능을 실제로 수행하는
자동차 부품이 3D로 나타난다**는 점입니다. 시험관이 "좌측 방향지시등을 켜십시오"라고 하면
스티어링 컬럼과 방향지시등 레버가 나타나 레버가 실제로 아래로 내려가는 모습을 보여 주고,
"와이퍼를 작동시키십시오"라고 하면 와이퍼 레버가 단수별로 내려가는 모습을 보여 줍니다.

라이브러리 의존성이 전혀 없습니다. 3D 렌더러부터 물리 · 채점 엔진 · 효과음까지 모두 직접 구현했습니다.

## 실행 방법

ES 모듈을 쓰기 때문에 `file://` 로 직접 열면 동작하지 않습니다. 정적 서버로 띄워 주세요.

```bash
# 저장소 폴더에서
python3 -m http.server 8000
# 또는
npx serve .
```

브라우저에서 <http://localhost:8000> 을 엽니다.
최신 Chrome · Edge · Firefox · Safari 에서 동작하며, 별도의 설치나 빌드 과정이 없습니다.

## 3D 부품 뷰어

구석 박스에 나타나는 부품은 10가지입니다. 시험관 지시, 감점 경고, 직접 조작 중
가장 우선순위가 높은 것이 자동으로 표시되고, `Tab` 으로 직접 넘겨 볼 수도 있습니다.

| 부품 | 표현 |
|---|---|
| 방향지시등 레버 | 스티어링 컬럼 좌측 레버가 좌회전 시 내려가고 우회전 시 올라감 |
| 와이퍼 레버 | 우측 레버가 단수(OFF·INT·LO·HI)만큼 내려가고 INT 에서는 조절 링이 회전 |
| 전조등 스위치 | 좌측 레버 끝 다이얼이 OFF → 미등 → 전조등으로 회전 |
| 비상점멸등 스위치 | 센터페시아 버튼이 눌리고 빨간 삼각형이 점멸 |
| 변속 레버 | 게이트를 따라 P · R · N · D 로 이동, 현재 단 점등 |
| 주차 브레이크 | 레버가 라쳇을 따라 올라가고 내려감 |
| 안전벨트 | 벨트가 B필러에서 버클까지 대각선으로 이동 |
| 엔진 시동 버튼 | 버튼이 눌리고 표시등이 대기(점멸) → 시동(녹색)으로 변화 |
| 스티어링 휠 | 조향각에 비례해 회전, 각도 표시 |
| 가속 · 제동 페달 | 밟는 정도에 따라 각각 기울어짐 |

## 시험 차량 — 1톤 화물차

제1종 보통면허 기능시험은 승용차가 아니라 **화물자동차**로 봅니다. 시험차량 기준은
**전장 465cm 이상 · 전폭 169cm 이상**이며, 실제로는 현대 포터 II · 기아 봉고 III 급
1톤 트럭이 쓰입니다. 2024년 7월 이들 차종에 **자동변속기 모델**이 운전교육용으로
추가되면서 1종보통 오토 기능시험이 가능해졌습니다.

이 프로그램은 장축 모델 제원을 따랐습니다.

| 항목 | 값 |
|---|---|
| 전장 × 전폭 × 전고 | 5.11m × 1.74m × 1.97m |
| 축거 | 2.64m (앞 오버행 1.05m · 뒤 오버행 1.42m) |
| 공차중량 | 1,900kg |
| 최소회전반경 | 약 5.1m |
| 운전자 눈높이 | 노면에서 1.62m |

캡오버 구조라 앞바퀴가 운전석 바로 아래에 있고 보닛이 없습니다. 그래서 승용차보다
**눈높이가 높아 코스가 잘 보이는 대신, 차체가 길어 회전과 직각주차가 훨씬 까다롭습니다.**
운전석 시점에서 보이는 실내(대시보드 · A필러 · 스티어링 휠 · 레버)도 이 제원에 맞춰
배치했습니다.

## 코스 규격

도로교통법 시행규칙 **[별표 23] 기능시험코스의 종류·형상 및 구조** 의 제1종 보통면허
기준을 따랐습니다.

| 항목 | 규격 | 프로그램 적용 |
|---|---|---|
| 코스 연장거리 | 300m 이상 | 318.0m |
| 도로의 폭 | 7m 이상 | 7.0m |
| 차로 | 3~3.5m 너비 2개 차로 | 중앙선 기준 좌우 각 3.5m |
| 중앙선 | 10~15cm 너비 | 12cm 황색 실선 |
| 길가장자리선 | 중앙선으로부터 3m 지점, 10~15cm 너비 | 3.0m 지점, 12cm 백색 실선 |
| 연석 | 길가장자리선에서 25cm 이상, 높이 10cm 정도 | 폭 25cm · 높이 10cm |

코스 영역은 축에 정렬된 사각형들의 합집합으로 정의하고, 그 경계(연석)를 그대로
차로 이탈 판정에 씁니다. 네 바퀴의 접지점으로 판정하며, 연석에 0.35m 이내로 접근하면
먼저 경고합니다. 교차 지점의 안쪽 모서리는 실제 도로처럼 우각부를 두어 넓혔습니다.
이것이 없으면 전장 5.11m · 최소회전반경 5.1m 인 화물차가 7m 도로 사이에서
90도 회전을 돌 수 없습니다.

중앙선 침범은 차로를 벗어난 것과 구분합니다. 중앙선을 실제로 넘었을 때만 감점하고,
길가장자리 쪽으로 치우친 것은 이탈 판정으로만 봅니다. 직각주차 전면 통로와
교차로 안쪽은 중앙선이 없으므로 판정에서 제외합니다.

코스는 **닫힌 순환 루프**입니다. 출발선을 나와 시계 방향으로 한 바퀴를 돌고,
출발했던 직선 도로의 **반대편 차로로 돌아와** 종료선에 정차합니다.

```
   서                                                       동
        출발선                                    신호교차로
   ──────●═══════════════════════════════════════════╦══════╗
   ──────●═══════╦═══════════════════════════════════╩══════╣
        종료선   ║   ┌───────────────────┐                   ║
                 ║   └────────┬─┬────────┘  ← 전면 통로      ║  경사로
       철길건널목 ║            │ │  직각주차구획              ║  (오르막→
                 ║            └─┘                            ║  정지구간→
                 ║                                           ║  내리막)
                 ╚═══════════════════════════════════════════╝
                        ◀── 돌발상황 ──── 가속구간 ──
```

- **직각주차** : 순환 코스 안쪽 전면 통로에서 폭 3.0m · 깊이 6.5m 구획으로 후진 진입,
  네 바퀴가 모두 들어간 채 정지 (2분 제한)
- **신호교차로** : 14초 녹색 / 3초 황색 / 12초 적색 주기. 정지선을 지켜 **직진 통과**
- **경사로** : 종단경사 10% · 오르막 12m · 최고 1.05m. 정지구간(2m)에 앞바퀴를 세우고
  30초 이내 출발. 브레이크를 놓으면 실제로 뒤로 밀린다
- **가속구간** : 30m 구간을 20km/h 이상으로 통과
- **돌발상황** : 표지판 점등 후 2초 이내 정지 + 비상점멸등
- **철길건널목** : 정지선 앞 일시정지

## 채점 기준

100점에서 시작해 감점하고 **80점 이상이면 합격**입니다.

### 실격 사유 — 도로교통법 시행규칙 [별표 24]

1. 특별한 사유 없이 출발선에서 **30초 이내 출발**하지 못한 때
2. 시험 코스를 어느 하나라도 **이행하지 아니한 때** (직각주차를 지나쳐 버린 경우 등)
3. 특별한 사유 없이 **교차로 내에서 30초 이상 정차**한 때
4. 안전사고를 일으키거나 **단 1회라도 차로를 벗어난 때**
5. 경사로 정지구간 이행 후 **30초를 초과하여 통과하지 못한 때**, 또는
   경사로 정지구간에서 후진하여 **앞범퍼가 경사로 사면을 벗어난 때**
6. 시험이 시작될 때부터 종료될 때까지 **좌석안전띠를 착용하지 않은 경우**

여기에 적색신호 정지선 통과(신호 위반), 시험시간 초과, 최종 점수 80점 미달을 더해
불합격 처리합니다.

### 렌더러

`src/gfx/renderer.js` 는 캔버스 2D 위에서 도는 소프트웨어 폴리곤 렌더러입니다.

1. 장면 그래프를 순회하며 각 면의 정점을 뷰 공간으로 변환
2. 근평면(`z <= -near`)에 대해 Sutherland–Hodgman 클리핑
3. 뉴웰 법선으로 평면 음영 계산 (모든 면은 양면으로 그리고 법선을 카메라 쪽으로 뒤집음)
4. 원근 투영 후 거리 기반 안개 적용
5. **레이어 우선, 그다음 먼 것부터** 정렬하여 채우기

레이어는 겹쳐 있는 평평한 노면(바닥 0 → 사면 1 → 아스팔트 2 → 차선 3)에만 쓰고,
입체물은 모두 레이어 4로 두어 깊이 순서대로 그려집니다. 부품 뷰어에서도 넓은 받침판만
레이어 0으로 내려 작은 부품을 덮지 않게 했습니다.

### 차량 거동

자전거 기구학(`θ' = v/L · tan δ`)에 종방향 동역학을 얹었습니다.
크리프 주행, 경사로에서의 후방 밀림, 속도에 따른 조향 응답 변화, 셀프 얼라이닝,
정지 마찰(브레이크가 중력 성분을 이기면 완전히 정지)을 모두 반영했습니다.
1톤 화물차의 질량(1,900kg)과 구동력으로 10% 경사로를 오르내리는 감각에 맞췄습니다.

### 시험 진행

단계 전환은 "어떤 조건을 만족했는가"가 아니라 **코스 주행거리**로 결정합니다.
코스 중심선을 하나의 폴리라인으로 두고, 매 프레임 차량 위치를 그 위에 투영해
진행거리 `s` 를 구합니다. 직전 값 주변만 탐색하고 값이 **뒤로 가지 않게** 하므로,
코스가 자기 자신과 가까워지는 지점(출발 직선과 철길 구간의 교차 지점 등)에서도
진행도가 튀지 않습니다.

각 단계에는 끝나는 지점 `until` 이 정해져 있고, 그 지점을 지나면 무조건 다음 단계로
넘어갑니다. 넘어가는 순간 아직 이행하지 않은 항목을 정산합니다 — 직각주차를
지나쳐 버렸으면 **미이행 실격**, 경사로에서 서지 않았으면 감점, 가속구간에서
20km/h 를 못 넘겼으면 감점. 그래서 어떤 단계도 조용히 건너뛰거나, 조건을 못 채워
그 자리에 멈춰 있는 일이 없습니다.

방향지시등 지시도 같은 진행거리 위에 배치했습니다. 각 지점마다 "켜야 하는 구간"과
"통과하는 지점"이 있어, 구간에 들어서면 시험관이 미리 안내하고 지점을 지날 때
켜져 있지 않으면 감점합니다.

---

## 알려진 제약

- **자동변속기 차량 기준**입니다. 수동변속기의 클러치 조작과 "엔진 시동 꺼짐" 감점은
  구현하지 않았습니다.
- 코스의 **전체 배치(각 구간의 배열 순서와 길이)** 는 별표 23이 정한 개별 규격
  — 도로 폭, 차선, 연석, 연장거리 — 을 만족시키되, 특정 시험장의 도면을 그대로
  옮긴 것은 아닙니다. 실제 시험장마다 배치가 다릅니다.
- 경사로의 종단경사(10%)와 직각주차 구획 치수(3.0m × 6.5m)는 별표 23에서 확인하지
  못해, 통상 알려진 값과 시험차량 제원으로부터 정한 값입니다.
- 시험관 음성 안내는 브라우저의 `speechSynthesis` 를 사용하므로,
  한국어 음성이 설치되지 않은 환경에서는 자막만 표시됩니다.
